## Cómo usar cada tipo de historia

- **teaser / anuncio / dato / frase / proceso / resumen / cta** → se suben tal cual.
- **encuesta / preguntas / auditoria** → se suben tal cual y encima ponés el sticker
  nativo de Instagram en el espacio libre del medio. El sticker nativo es el que
  genera la respuesta; el texto del diseño es solo la pregunta.
  - lun-3: encuesta → Sí, funcionó / Sí, pero nada / Nunca probé
  - mar-2: caja de preguntas → "Mi rubro es…"
  - mie-3: encuesta → Promocionar / Campañas / Nada todavía
  - jue-3: caja de preguntas → "Mi web es…"
  - vie-3: encuesta → No llegan consultas / No tengo tiempo / No sé qué postear
- **repost** → se suben como fondo y encima pegás el posteo compartido del feed
  (compartir → agregar a tu historia) más el sticker de "Ver publicación".
- **sab-3-equipo** → poné una foto de ustedes de fondo antes de subirla.
